01개요

이 사이트의 목적은 반도체 분야 감수 담당자가 내 영상을 보고 "외주를 맡겨도 된다"고 판단하게 하는 것입니다. 그래서 모든 기능은 두 가지를 보여주는 데 집중합니다. 하나는 영상 퀄리티, 다른 하나는 반도체 정보의 정확성입니다.

  • 범위: 포트폴리오 사이트에서 방문자가 보고 쓰는 화면의 기능
  • 제외: 관리자 업로드 도구, 결제, 회원 시스템 (필요해지면 나중에 추가)

02페르소나

이름
김깐깐
역할
반도체 분야 동영상 감수 담당자. 영상 외주를 맡길지 결정한다
사이트에 온 목적
업로드된 작업 영상을 보고 외주를 맡겨도 되는지 판단한다
보는 상황
근무 중 사무실 데스크탑·랩탑. 비교 대상이 없어 영상을 끝까지 본다
꼭 확인하고 싶은 것
영상 퀄리티, 반도체 정보가 정확하고 양질인지

03핵심 사용자 시나리오

김깐깐은 비교할 업체 없이 이 사이트만 보므로, 영상 하나를 끝까지 자세히 보는 흐름이 가장 중요합니다.

  1. 메인 화면에서 어떤 반도체 영상을 만드는 사람인지 한눈에 파악한다.
  2. 영상 목록에서 주제(공정, 장비, 소자 등)나 유형으로 골라 볼 영상을 고른다.
  3. 영상 상세 페이지에서 고화질로 끝까지 재생하며 퀄리티를 확인한다.
  4. 같은 페이지에서 영상의 기획 의도, 다룬 반도체 개념, 참고한 자료를 읽고 정보의 정확성을 판단한다.
  5. 작업자 소개와 작업 방식을 확인한다.
  6. 맡겨도 된다고 판단하면 문의 양식이나 연락처로 외주를 문의한다.

04기능 목록

필수 기능 5개는 모두 김깐깐이 확인하려는 두 가지, 퀄리티와 정보 정확성에 연결됩니다.

ID기능명설명우선순위확인 포인트
F-01메인 소개반도체 영상 전문임을 한 문장과 대표 영상으로 보여준다필수퀄리티
F-02영상 목록썸네일, 제목, 길이, 주제 태그를 카드로 보여준다필수퀄리티
F-03주제·유형 필터공정, 장비, 소자 등 주제와 교육·홍보 등 유형으로 거른다권장정보 정확성
F-04고화질 영상 플레이어화질 선택, 전체화면, 구간 이동, 자막 켜고 끄기필수퀄리티
F-05영상 상세 설명기획 의도, 다룬 반도체 개념, 대상 시청자, 담당 범위필수정보 정확성
F-06참고 자료 표기영상에 쓴 정보의 출처와 감수 여부권장정보 정확성
F-07챕터(타임라인)주요 개념이 나오는 시점으로 바로 이동선택정보 정확성
F-08작업자 소개경력, 작업 범위, 작업 과정(기획부터 감수 반영까지)권장둘 다
F-09외주 문의문의 양식 또는 이메일·연락처필수둘 다

05주요 기능 상세

필수 기능을 먼저 정의합니다. 권장·선택 기능은 기획서 단계에서 더 자세히 정합니다.

F-01메인 소개

  • 처음 화면에 "반도체 영상을 만드는 사람"임을 한 문장으로 보여준다.
  • 대표 영상 1개를 바로 재생할 수 있게 둔다.
  • 영상 목록과 문의로 가는 버튼을 둔다.

F-02영상 목록

  • 카드 하나에 썸네일, 제목, 영상 길이, 주제 태그를 보여준다.
  • 카드를 누르면 해당 영상 상세 페이지로 이동한다.
  • 최신순으로 정렬한다.

F-04고화질 영상 플레이어

  • 원본 화질로 재생할 수 있고, 화질을 직접 고를 수 있다.
  • 전체화면, 구간 이동, 볼륨, 자막 켜고 끄기를 지원한다.
  • 감수자가 세부 화면(도식, 수치, 용어)을 확인할 수 있게 일시정지 화면도 선명해야 한다.

F-05영상 상세 설명

  • 플레이어 아래에 기획 의도, 대상 시청자, 다룬 반도체 개념을 적는다.
  • 내가 맡은 범위(기획, 촬영, 편집, 모션그래픽 등)를 표시한다.
  • 주요 용어는 짧은 설명과 함께 적어 정보 이해도를 보여준다.

F-09외주 문의

  • 모든 페이지에서 문의로 바로 갈 수 있다.
  • 문의 양식은 회사명, 담당자명, 연락처, 영상 주제, 희망 일정을 받는다.

06비기능 요구사항

김깐깐은 사무실 PC로 보므로 데스크탑 화면을 기준으로 설계합니다.

  • 환경: 데스크탑·랩탑 브라우저(Chrome, Edge) 우선. 모바일은 깨지지 않는 수준
  • 영상 품질: 원본 해상도 재생, 압축으로 글자·도식이 뭉개지지 않을 것
  • 성능: 영상을 끝까지 보므로 끊김 없이 재생될 것
  • 회사 네트워크: 사내망에서 막히지 않는 영상 호스팅 방식일 것

07확인이 필요한 사항

  • 영상을 어디에 올릴지 (자체 업로드, YouTube, Vimeo)
  • 주제 태그 분류 기준 (공정·장비·소자 외에 추가할 것)
  • 참고 자료·감수 여부를 영상마다 공개할 수 있는지 (고객사 보안 이슈)
  • 외주 문의를 양식으로 받을지, 이메일만 열어둘지
기획서 작성 전 단계의 기능정의서 초안입니다.
